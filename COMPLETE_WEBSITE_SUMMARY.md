## 🎨 Visual Design Language

### **Typography Hierarchy**

```
Hero Headline:       text-6xl md:text-7xl lg:text-8xl (serif)
Section Headlines:   text-4xl md:text-5xl lg:text-6xl (serif)
Subheadings:        text-xl md:text-2xl
Body Text:          text-base leading-relaxed
Small Text:         text-sm
Labels:             text-xs tracking-[0.2em] uppercase
```

### **Color Palette**

```css
Primary (Warm Beige):    hsl(40 20% 92%)      #EDE9E3
Secondary (Charcoal):    hsl(220 15% 20%)     #2B2F35
Accent (Muted Gold):     hsl(43 74% 66%)      #E5C87F
Background:              hsl(40 15% 97%)      #F9F7F5
Foreground:              hsl(220 15% 15%)     #232629
```

### **Spacing Philosophy**

```
Section Padding:     py-24 lg:py-32 (96px → 128px)
Generous Spacing:    py-32 lg:py-40 (Hero, CTA)
Content Gap:         gap-12 lg:gap-16 (48px → 64px)
Card Padding:        p-8 lg:p-10 (32px → 40px)
Button Padding:      px-10 py-5 (40px × 20px)
```

### **Animation Timing**

```
Fast:           200ms (icon micro-interactions)
Standard:       300ms (link hovers)
Smooth:         600ms (content reveals)
Premium:        800ms (large headlines)
Atmospheric:    1000ms (background elements)
```

### **Shadow System**

```css
Luxury Small:    0 2px 8px rgba(0, 0, 0, 0.06)
Luxury Medium:   0 4px 16px rgba(0, 0, 0, 0.08)
Luxury Large:    0 8px 24px rgba(0, 0, 0, 0.10)
Luxury XL:       0 12px 32px rgba(0, 0, 0, 0.12)
```

## 🎬 Motion Design Strategy

### **1. Hero Section**
```
Headline:    Fade up, 800ms, delay: 300ms
Subheading:  Fade up, 600ms, delay: 500ms
CTA:         Fade up, 600ms, delay: 700ms
Background:  Scale + fade, 1000ms, delay: 0ms
```

### **2-6. Content Sections**
```
Pattern: Scroll-based reveals
Label:    Fade + slide up, staggered
Headline: Fade + slide up, longer duration
Cards:    Fade + slide up, indexed delays
Hover:    Lift, scale, or shift effects
```

### **7. Call To Action**
```
Staggered entrance over 2 seconds
Button arrow slides right on hover
Scale down (98%) on tap
```

### **8. Footer**
```
Columns fade up left to right (0-400ms)
Social icons lift 2px on hover
Links brighten smoothly (300ms)
```

**Every animation feels discovered, not announced** ✨

## ♿ Accessibility Features

### **Semantic HTML**
```tsx
<header> <nav> <main> <section> <article> <aside> <footer>
<h1> through <h6> (proper hierarchy)
<button> (interactive elements)
<address> (contact information)
```

### **ARIA Labels**
```tsx
aria-label="descriptive text"
aria-labelledby="element-id"
role="button" (where appropriate)
```

### **Keyboard Navigation**
- Tab through all interactive elements
- Enter/Space to activate buttons
- Escape to close modals
- Proper focus states (visible outline)
- No keyboard traps

### **Color Contrast**
- Text: WCAG AA compliant (4.5:1 minimum)
- Interactive elements: Clear hover/focus states
- Borders: Visible but subtle

### **Motion Considerations**
```tsx
viewport={{ once: true }}  // Animations trigger once
```
- Respects `prefers-reduced-motion` (can be added)
- Not overly aggressive or jarring
- Smooth, premium timing

### **Screen Reader Support**
- Descriptive link text (not "click here")
- Alt text for images (when added)
- Proper heading hierarchy
- Landmark roles for navigation

**Inclusive design, professional implementation** ♿

## 🔧 Customization Guide

### **Colors (tailwind.config.ts)**

```typescript
'--accent': 'hsl(43 74% 66%)',        // Change gold accent
'--card': 'hsl(40 20% 92%)',          // Change warm beige
'--foreground': 'hsl(220 15% 15%)',   // Change text color
```

### **Typography (globals.css)**

```css
.font-serif { font-family: 'Your Serif Font', Georgia, serif; }
body { font-family: 'Your Sans Font', system-ui, sans-serif; }
```

### **Section Content**

Each section component accepts props (can be added):
```tsx
<Hero 
  headline="Your Headline"
  subheading="Your Subheading"
  ctaText="Your CTA"
/>
```

### **Images**

Replace placeholder divs:
```tsx
<div className="aspect-[4/3] bg-muted"> {/* Placeholder */}
  <Image 
    src="/your-image.jpg"
    alt="Description"
    fill
    className="object-cover"
  />
</div>
```

### **Contact Information (Footer)**

```tsx
<p>Your Studio Name</p>
<p>Your Address</p>
<a href="mailto:your@email.com">your@email.com</a>
<a href="tel:+1234567890">+1 (234) 567-890</a>
```

### **Social Links (Footer)**

```tsx
const socialLinks = [
  { name: "Platform", href: "https://...", icon: <svg>...</svg> },
];
```
