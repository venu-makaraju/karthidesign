## 🎬 Scroll-Based Reveal Animations

### **Animation Sequence**

```
Header:    Fades up (0.0s)
Card 01:   Fades up (0.0s)
Card 02:   Fades up (0.15s delay)
Card 03:   Fades up (0.30s delay)
Card 04:   Fades up (0.45s delay)
CTA Card:  Fades up (0.60s delay)

Within Each Card:
Badge:     Immediate
Title:     Immediate  
Desc:      Immediate
Point 1:   0.2s delay
Point 2:   0.3s delay
Point 3:   0.4s delay
```

**Staggered Elements:**
- Cards stagger by 150ms
- Points within cards stagger by 100ms
- Creates rhythmic, gentle reveal
- Never rushed or aggressive

### **Animation Properties**

**Card Entrance:**
```tsx
initial={{ opacity: 0, y: 30 }}
whileInView={{ opacity: 1, y: 0 }}
transition={{ duration: 0.8, ease: [0.16, 1, 0.3, 1] }}
```
- 30px upward reveal
- Smooth 0.8s duration
- Custom easing curve
- Feels discovered, not announced

**Point Reveal:**
```tsx
initial={{ opacity: 0, x: -10 }}
whileInView={{ opacity: 1, x: 0 }}
transition={{ duration: 0.5, delay: 0.2 + i * 0.1 }}
```
- Slides 10px from left
- Staggered by 100ms per item
- Subtle, not dramatic
- Adds life to static content
