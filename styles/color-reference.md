# Color Reference - Karthi Design Solutions

## Light Mode Colors

### Primary Colors
```css
--primary: oklch(0.72 0.042 70)              /* Warm Beige/Sandstone */
--primary-foreground: oklch(0.98 0.008 85)   /* Light cream text */

--secondary: oklch(0.32 0.015 260)           /* Charcoal/Deep Slate */
--secondary-foreground: oklch(0.98 0.008 85) /* Light text */

--accent: oklch(0.68 0.08 75)                /* Muted Gold */
--accent-foreground: oklch(0.98 0.008 85)    /* Light text */
```

### Backgrounds
```css
--background: oklch(0.98 0.008 85)           /* Warm creamy white */
--foreground: oklch(0.25 0.012 265)          /* Deep charcoal text */

--card: oklch(0.96 0.015 75)                 /* Warm beige tint */
--card-foreground: oklch(0.25 0.012 265)     /* Deep charcoal */

--popover: oklch(0.98 0.008 85)              /* Subtle popover */
--popover-foreground: oklch(0.25 0.012 265)  /* Deep charcoal */
```

### Muted & States
```css
--muted: oklch(0.93 0.012 75)                /* Light beige */
--muted-foreground: oklch(0.48 0.015 265)    /* Medium gray */

--destructive: oklch(0.55 0.18 25)           /* Subtle red */
--destructive-foreground: oklch(0.98 0.008 85)
```

### Borders & Focus
```css
--border: oklch(0.88 0.008 75)               /* Soft border */
--input: oklch(0.88 0.008 75)                /* Input border */
--ring: oklch(0.68 0.08 75)                  /* Muted gold focus ring */
```

## Tailwind Class Reference

### Backgrounds
- `bg-primary` - Warm beige/sandstone
- `bg-secondary` - Charcoal/deep slate
- `bg-accent` - Muted gold
- `bg-background` - Page background
- `bg-card` - Card background
- `bg-muted` - Muted background

### Text Colors
- `text-foreground` - Primary text
- `text-muted-foreground` - Secondary text
- `text-primary` - Primary color text
- `text-secondary` - Secondary color text
- `text-accent` - Accent color text

### Border Colors
- `border-border` - Standard border
- `border-primary` - Primary border
- `border-accent` - Accent border

### Utility Classes
- `shadow-luxury` - Subtle shadow
- `shadow-luxury-lg` - Medium shadow
- `shadow-luxury-xl` - Large shadow
- `border-luxury` - Subtle border
- `glass-luxury` - Frosted glass effect

## Color Psychology

### Warm Beige/Sandstone (Primary)
- **Emotion**: Comfort, warmth, earthiness
- **Use**: Primary actions, brand elements, warmth
- **Message**: Approachable luxury, natural elegance

### Charcoal/Deep Slate (Secondary)
- **Emotion**: Sophistication, stability, professionalism
- **Use**: Text, secondary actions, grounding elements
- **Message**: Timeless, refined, trustworthy

### Muted Gold (Accent)
- **Emotion**: Prestige, quality, exclusivity
- **Use**: Highlights, hover states, special features
- **Message**: Premium, valuable, attention to detail
